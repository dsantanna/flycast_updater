========================================
       FLYCAST UPDATER - CHANGELOG
========================================

Versão 4.2 (Another Day Edition)
----------------------------------------
- **Detecção de Hardware Gráfico:** Nova seção na aba de Vídeo que identifica automaticamente todas as placas de vídeo (integradas e dedicadas) utilizando varredura silenciosa via PowerShell.
- **Sugestão Inteligente de Drivers:** O sistema reconhece a fabricante da GPU (NVIDIA, AMD ou Intel) e habilita um botão com link direto para a página oficial de download de drivers, sugerindo a atualização de forma amigável.
- **Layout Dinâmico para Múltiplas GPUs:** A interface insere separadores visuais elegantes automaticamente e ajusta o espaçamento quando o usuário possui mais de uma placa de vídeo (comum em notebooks).

Versão 4.1 (Another Day Edition - Major Release)
----------------------------------------
- **Tradução em Tempo Real (i18n Dinâmico):** Ao alterar o idioma no menu superior, a interface gráfica é atualizada instantaneamente, eliminando a necessidade de reiniciar o aplicativo.[cite: 6]
- **Cobertura Global Completa de Idiomas:** Todos os 10 idiomas suportados (PT-BR, EN-US, ES-ES, FR-FR, DE-DE, ZH-CN, JA-JP, RU-RU, AR-SA, HI-IN) foram totalmente preenchidos e revisados para contemplar todas as abas, botões, logs e opções avançadas.[cite: 6]
- **Aviso Inteligente de Atualização do Launcher:** O sistema agora exibe um alerta claro e multilíngue quando uma nova versão do próprio *Flycast Updater* é detectada, informando que a ferramenta será atualizada em conjunto com o emulador.[cite: 6]

Versão 4.0 (Another Day Edition - Major Release)
----------------------------------------
- **Internacionalização Global (i18n):** O Flycast Updater agora fala com o mundo! Suporte nativo e instantâneo para os 10 idiomas mais falados (PT-BR, EN-US, ES-ES, FR-FR, DE-DE, ZH-CN, JA-JP, RU-RU, AR-SA, HI-IN).[cite: 6]
- **Assistente Inteligente de BIOS:** Novo motor autônomo que varre, detecta, auto-renomeia arquivos `.bin` incorretos e até extrai as BIOS (`dc_boot.bin` e `dc_flash.bin`) diretamente de pacotes `.zip` para a pasta correta.[cite: 6]
- **Custom Paths Dinâmicos:** Suporte completo à configuração de pastas personalizadas para BIOS, VMU, Save States e Saves de Jogo, com criação física automática de diretórios no Windows e integração total ao arquivo `emu.cfg`.[cite: 6]
- **Restaurador de Backup Avançado:** O descompactador de nuvem agora age com inteligência contextual. Ao restaurar um backup antigo, ele direciona automaticamente os arquivos do VMU e Mappings para os caminhos personalizados ativos.[cite: 6]
- **Gerenciamento Passivo de Nuvem:** Implementado sistema de limite de armazenamento para os Cloud Saves (1, 3, 5, 10, 15 ou Ilimitado). O motor agora limpa e deleta automaticamente os backups mais velhos para poupar espaço no Google Drive / OneDrive.[cite: 6]
- **Super Logger Integrado (Aba de Logs):** O motor interno ganhou um sistema de eventos detalhado (Modo Tagarela). Uma nova aba "Logs" foi adicionada à interface, atualizando em tempo real com todo o fluxo de diagnóstico e auditoria.[cite: 6]
- **UX & UI Design Refinado:** Novo layout adaptativo com a Branch "Dev" priorizada, campos de texto dinâmicos que sugerem as ramificações padrões baseadas no local de instalação e separadores visuais que melhoram a fluidez da interface.[cite: 6]
- **Sincronização de Mappings (Opcional):** Adicionado suporte para incluir o backup dos arquivos de mapeamento de controles (`.cfg`) diretamente nos pacotes salvos na nuvem.[cite: 6]

Versão 3.1 (Emerald Coast Edition - Bugfix)
----------------------------------------
- **Modo CLI Persistente (-nogui na UI):** Adicionado novo switch na aba de Nuvem para permitir que o usuário desative permanentemente o ambiente gráfico.[cite: 6]
- **Correção da Autoatualização Gráfica:** Ajustado o encerramento do processo de auto-update utilizando `os._exit(0)`, permitindo que o script `.bat` substitua o executável com sucesso.[cite: 6]
- **Mapeamento Exato da API Gráfica:** Correção definitiva dos índices do parâmetro `pvr.rend` no `emu.cfg` (`0 = OpenGL`, `1 = DirectX 9`, `2 = DirectX 11`, `4 = Vulkan`).[cite: 6]

Versão 3.0 (Emerald Coast Edition)
----------------------------------------
- **Interface Gráfica Expandida (Hub Completo):** Adicionadas novas abas dedicadas a "Configurar Emulador", "Vídeo" e "Restaurar Saves", transformando o utilitário em um gerenciador total do ecossistema Flycast.[cite: 6]
- **Gerenciador de Saves na Nuvem (Restauração):** Interface gráfica inteligente que varre automaticamente a subpasta de backup na nuvem (Google Drive/OneDrive) e lista os arquivos `.zip` em ordem cronológica.[cite: 6]
- **Olho Mágico (Toggle de Senha):** Adicionado botão interativo na aba de configurações para alternar entre mascarar (`*`) e exibir a senha ou Web API Key do RetroAchievements.[cite: 6]
- **Blindagem do Arquivo de Configuração:** Uso do `RawConfigParser(strict=False)` para leitura e escrita em modo bruto no `emu.cfg`.[cite: 6]

Versão 2.0 (Gold Master - GUI Edition)
----------------------------------------
- **Nova Interface Gráfica (GUI):** Desenvolvida com CustomTkinter, trazendo um design moderno, tema escuro e responsividade.[cite: 6]
- **Mutações de Ação Inteligentes:** O botão principal agora altera dinamicamente seu texto (Instalar, Atualizar, Jogar) com base na verificação em tempo real (em background) entre a versão local e a da nuvem.[cite: 6]
- **Semáforo de Status do Emulador:** Novo indicador visual que mostra se o emulador está ausente, desatualizado (amarelo) ou pronto para jogar (verde).[cite: 6]

Versão 1.2 (Cloud Save Edition)
----------------------------------------
- **Integração de Cloud Saves:** Novo módulo (`cloud_saves.py`) para detecção passiva e backup automatizado de arquivos de progresso (VMU e SRAM) utilizando instâncias locais do Google Drive e OneDrive.[cite: 6]
- **Sistema de Rollback:** Implementada criação automática de "cápsulas do tempo" (backup estrutural do emulador) antes de sobreposições de atualização.[cite: 6]
